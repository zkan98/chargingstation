# 일렉서치(ElecSearch) - 전기차 충전소 추천 웹 서비스 프로젝트

# 프로젝트 개요

<aside>
**프로젝트명:** 일렉서치 (전기차 충전소 추천 웹페이지)

**개발 기간:** 2024.07.01 ~ 2024.08.01

**기여도:** 팀장 (백엔드 4명, 프론트엔드 1명, 총 5명)

</aside>

## 목표

- 사용자에게 주변 전기차 충전소를 추천하고, 리뷰를 작성할 수 있는 웹 서비스 개발
- 충전소 사업자가 충전소 정보를 관리할 수 있는 시스템 구축

# 기술 스택

### 백엔드

- 사용 언어: Java
- 프레임워크: Spring Boot, JPA
- 데이터베이스: MySQL
- 보안: Spring Security, JWT

### 프론트엔드

- 사용 언어: JavaScript
- 프레임워크: React
- 라이브러리: Kakao Maps API

### 개발 도구

- 버전 관리: Git, GitHub
- 배포 환경: GCP

# 주요 기능

## 1. 전기차 충전소 추천 및 검색

- **상세 설명**
    - 사용자의 현재 위치 기반 주변 전기차 충전소 추천
    - 지도 API를 활용한 충전소 위치 시각화 및 상세 정보 제공
    - 충전소 검색 및 필터링 기능
- **구현 방법**
    - 사용자 위치 정보 수집 및 서버 전달, 데이터베이스 거리 계산/필터링
    - 페이징(Pageable) 적용으로 효율적인 데이터 로드 구현

## 2. 리뷰 기능 개선 및 안정화

- **상세 설명**
    - 충전소 리뷰 작성 및 정보 공유 기능
    - 리뷰 시스템 안정화 및 기능 보완
- **성과**
    - 3회 주요 업데이트를 통해 리뷰 기능 80% 수정 및 보완
    - 페이지 로딩 속도 20% 향상
    - 에러 발생률 30% 감소

## 3. 충전소 사업자 도메인 관리

- **상세 설명**
    - 충전소 정보 등록, 수정, 삭제 관리 시스템 구축
    - 사업자 인증 및 권한 관리 시스템 구현
